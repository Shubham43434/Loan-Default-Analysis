# Loan Default & Financial Risk Analysis

## Project Overview
An interactive data analytics project developed using Microsoft Power BI to analyze loan performance, borrower demographics, and financial risk patterns.

## Objectives
- Analyze loan distribution and default trends.
- Identify patterns across borrower demographics and financial attributes.
- Evaluate loan performance across different categories.
- Track changes in loan amounts and defaults over time.

## Tools & Technologies
- Microsoft Power BI
- DAX (Data Analysis Expressions)
- Power Query
- Data Visualization
- Exploratory Data Analysis

## Key Analysis
- Loan analysis by purpose, credit score, and education.
- Borrower segmentation by age, income, employment, and marital status.
- Default analysis across different employment categories.
- Year-over-Year (YoY) and Year-to-Date (YTD) financial analysis.
- Comparative analysis of loan amounts and default trends.

## Dashboard Pages

### 1. Loan Overview
Overall loan performance, loan distribution, and financial KPIs.

### 2. Applicant Demographics
Analysis of borrower characteristics, including age, employment, education, and marital status.

### 3. Financial Risk Analysis
Analysis of loan defaults, credit profiles, and financial trends.
